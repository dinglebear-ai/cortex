## Phase 4 gate

```bash
pnpm --dir web install --frozen-lockfile
pnpm --dir web lint
pnpm --dir web typecheck
pnpm --dir web test
pnpm --dir web build
node web/scripts/audit-aurora.mjs
cargo test web_app --lib
cargo build --release
```

Required proof:

- pinned versions and Aurora full SHA are visible in lock/status
- static export is reproducible
- no external runtime fonts, mutable Aurora URLs, or source maps
- real release binary serves deep links and assets with correct CSP/cache/ETag
- script CSP contains exact hashes and no unsafe-inline/eval
- component audit passes before feature UI composition begins
