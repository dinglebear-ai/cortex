# install-cortex

This plugin contains the guided `install-cortex` skill and the Cortex HTTP MCP client connection in `.mcp.json`. It guides server, client-only, or host-agent setup through the canonical installer and `cortex setup start`, then verifies authenticated access. Collection capabilities require explicit selection; unavailable prerequisites remain visible. Advanced settings use `--set` and `--secret-file`, and `setup effective --json` reports redacted configuration provenance. The separate `cortex` plugin contains investigation and observability skills. No automatic lifecycle hooks are shipped.
